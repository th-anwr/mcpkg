Accepted: a GitHub/GitLab repo (optionally a monorepo folder), an npmjs.com or pypi.org package page, or an https MCP endpoint.

What happens next

  1. Repo health: commits, releases, open pull requests and issues.
  2. Security scan of the package users actually install, plus known-vulnerability and malicious-package lookups.
  3. Smoke test: we install it in a sandbox and run the MCP handshake with no network. API keys get placeholder values, so "needs an API key" is a normal result.
  4. Description written by an open-source model and checked against your README.
  5. Score and page, re-checked weekly and on every new release.

Best: publish to the official MCP Registry

Servers published to registry.modelcontextprotocol.io are picked up automatically within an hour, including your declared environment variables and arguments, which makes our install steps exact.
